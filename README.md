## About

I’m a self-taught software developer with professional experience from **2002–2019**, working my way up from junior roles into senior-level development work. Since then, I’ve stayed in it through independent product and client work instead of drifting off into theory. I’ve been building sites, tools, platform features, auth flows, integrations, and backend-connected frontend work that had to actually function once real people touched it.

Most of my recent work has been in **React, TypeScript, JavaScript, Vite, Next.js API routes, Supabase/Postgres, OAuth, API integration, deployment, DNS, SSL, hosting, and UI/UX cleanup**. I’m good at walking into a system that already has problems, figuring out what’s actually wrong, and getting it back into a shape where people can use it without fighting it.

I don’t really care about sounding impressive for its own sake. I care about whether the thing works, whether it makes sense, whether it’s maintainable, and whether somebody else is going to hate me later when they open the code.

## How I Work

- I like clear logic more than clever code
- I’m comfortable in inherited systems
- I don’t panic when a project is already messy
- I care about frontend behavior because users feel bad architecture immediately
- I’d rather make something understandable than make it look fancy in a code review
- I ship, then clean up what needs cleaning up, then keep going
